Política de Privacidad — Oye, ¿leíste esto?

Esta aplicación no recolecta, almacena ni comparte datos personales de terceros.

Los únicos datos que maneja son las credenciales de acceso (tokens de autenticación) necesarias para publicar contenido en la cuenta de TikTok del propio desarrollador, usando la API oficial de TikTok (Content Posting API).

No se recopila información de otros usuarios de TikTok ni de visitantes. Las credenciales se almacenan localmente y no se comparten con ningún tercero.
